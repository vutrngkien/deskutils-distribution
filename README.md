# DeskUtils Distribution

Official public distribution repository for DeskUtils, a private-source macOS
menu bar utility app.

This repository contains only:

- The public landing page and installation guide.
- GitHub Release assets such as the DMG, Sparkle ZIP, checksums and appcast.
- The GitHub Pages deployment workflow.

It does not contain the DeskUtils application source code or private signing
keys.

## Website

The static website lives in [`site/`](site/) and is deployed to:

<https://vutrngkien.github.io/deskutils-distribution/>

Preview it locally with:

```bash
python3 -m http.server 8080 --directory site
```

Then open <http://localhost:8080>.

## Downloads

The landing page links to the stable asset name from the latest GitHub Release:

```text
https://github.com/vutrngkien/deskutils-distribution/releases/latest/download/DeskUtils.dmg
```

Each release should contain:

```text
DeskUtils.dmg
DeskUtils-<version>.zip
SHA256SUMS.txt
appcast.xml
```

`site/appcast.xml` must be generated by Sparkle after the versioned ZIP is
uploaded. Never edit Sparkle signatures manually and never commit the EdDSA
private key.

## GitHub Pages setup

In repository settings, open **Pages** and select **GitHub Actions** as the
source. Pushing `site/` changes to `main` then runs the deployment workflow.
The workflow intentionally refuses to publish until `site/appcast.xml` exists
and the latest `DeskUtils.dmg` release asset is publicly reachable.
