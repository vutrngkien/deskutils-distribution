Good to know

Questions,
answered.

Is DeskUtils free?

Yes. The current DeskUtils beta is free to download and use. Pricing may change for future stable releases, but we will always communicate changes clearly.

Why does macOS show a security warning?

The current beta is not notarized by Apple yet. macOS may ask you to confirm it in System Settings → Privacy & Security. Follow the installation guide; never disable Gatekeeper.

Which macOS versions are supported?

DeskUtils currently requires macOS 26 or later because it uses the latest native macOS interface technologies.

What permissions are required?

Clipboard history and Prevent Sleep need no special permission. Clean Keyboard and direct paste use Accessibility. Color Picker uses Screen & System Audio Recording to read the pixel under your pointer.

Where is clipboard history stored?

It is stored locally inside DeskUtils' sandboxed Application Support container. Clipboard content is not uploaded to DeskUtils servers.

How are updates delivered?

DeskUtils uses Sparkle to check a signed update feed hosted with the official releases. You choose when to download and install an update.
