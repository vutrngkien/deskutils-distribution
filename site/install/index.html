Step one

Install the app

DeskUtils is distributed as a standard macOS disk image. Download it only from the official DeskUtils distribution repository.

  1. Download DeskUtils.dmgUse the download button above to get the latest beta release.
  2. Open the disk imageDouble-click DeskUtils.dmg in your Downloads folder.
  3. Move DeskUtils to ApplicationsDrag DeskUtils into the Applications folder shown in the installer window.
  4. Launch from ApplicationsOpen Finder → Applications, then double-click DeskUtils.

First launch

If macOS blocks DeskUtils

Because this beta is not notarized, macOS may say it cannot verify the developer. If you downloaded DeskUtils from the official release page and want to continue:

  1. Try opening DeskUtils onceDismiss the warning after it appears. This makes the override available in System Settings.
  2. Open Privacy & SecurityGo to System Settings → Privacy & Security and scroll down to Security.
  3. Click Open AnywayThe button is available for a limited time after the blocked launch attempt.
  4. Confirm OpenEnter your Mac password if requested. DeskUtils is then saved as an exception.

For more context, read Apple's official guide to opening apps safely.

Feature permissions

Grant only what you use

DeskUtils requests system access when a feature needs it. You can keep using the remaining utilities if you decline an optional permission.

AccessibilityLets Clean Keyboard block input and lets Clipboard Manager paste directly into the previous app.
Screen RecordingLets Color Picker read the pixel under your pointer. DeskUtils does not record or upload your screen.
Network accessUsed by Sparkle to check the official signed update feed. Clipboard content is never included.
No extra accessClipboard monitoring and Prevent Sleep do not require a separate macOS privacy permission.

Optional integrity check

Verify your download

Each release includes a SHA256SUMS.txt file. Compare its DeskUtils.dmg value with the result of this Terminal command:

shasum -a 256 ~/Downloads/DeskUtils.dmg

The two hashes must match exactly. If they do not, delete the DMG and download it again from the official release page.
